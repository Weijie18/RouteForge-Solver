# MT_RouteForge-Solver
1. RouteForge Solver：面向即时配送订单与骑手任务匹配问题的自动策略探索与元启发式求解框架.doc 是Agent的说明文档（说明书）
2. autosolver_portable.zip 是Agent材料的压缩包
3. autosolver_portable 文件夹，包含autosolver_portable.zip解压之后的所有文件
   -3.1 autosolver_workbench 文件夹包含Agent的所有python代码
   -3.2 cases 文件夹包含测试算例
   -3.3 clean_solver.py 是目前为止生成的最好的算法代码
   -3.4 PORTABLE_README.md 是autosolver_portable文件夹中Agent的说明文件
